# CyberShield
Enterprise cybersecurity operations platform frontend built with HTML5, CSS3 and Vanilla JavaScript.

## Run
Open `index.html` in a browser. No build step or server is required.

## Notes
- Dashboard is full-screen and footer-free.
- Metrics/intelligence are fictional demonstration data.
- Authentication is frontend-only demo behavior.
- External font import is from Google Fonts; the UI otherwise uses no framework.
