# CYBERSHIELD — ENTERPRISE CYBERSECURITY OPERATIONS PLATFORM

Build a complete, highly professional, production-style cybersecurity platform named:

**CYBERSHIELD**
**Cybersecurity Operations & Threat Intelligence Platform**

The website must look like a real enterprise cybersecurity SaaS product, not a beginner project, college assignment, generic template, or obviously AI-generated website.

---

## 1. TECHNOLOGY

Use only:

* HTML5
* CSS3
* Vanilla JavaScript

Do NOT use:

* React
* Bootstrap
* Tailwind CSS
* jQuery
* Any UI framework

Keep all HTML, CSS and JavaScript properly separated.

Use clean, scalable and maintainable code.

---

# 2. OVERALL DESIGN DIRECTION

Create a premium **Enterprise Security Operations Center (SOC)** visual identity.

The design should feel:

* Professional
* Technical
* Secure
* Premium
* Minimal
* Modern
* Enterprise-grade
* Trustworthy

### Color system

Primary:

* Near-black
* Deep graphite
* Dark charcoal

Accent:

* Electric cyan
* Cool blue

Supporting:

* Security green
* Amber for warnings
* Red for critical threats

Use accent colors carefully.

Do NOT create an excessively neon interface.

Avoid:

* Gaming-style UI
* Hacker clichés
* Skull graphics
* Excessive glowing text
* Excessive gradients
* Excessive glassmorphism
* Random futuristic graphics
* Excessive animations
* Emojis
* Keyboard-symbol icons

Use subtle shadows, borders and controlled glow effects.
